# 学生选课展示案例

[课程与教学班样例](catalog-demo.sql)包含 8 门课程、9 个教学班。[课程分类与特殊要求示例](catalog-demo.yml)展示如何按课程号配置素质拓展细分，按教学班号配置已公布的特殊要求。测试在独立的 H2 内存库中载入两份文件，结束后销毁数据。

在仓库的 `backend` 目录执行以下命令，按课程类型和面向对象逐项复现。演示轮次编号为 `910`，测试使用固定时间，无需启动前端或连接共享云库。

```shell
mvn -B -Dtest=SelectionServiceTest test
```

| 筛选课程类型 | 预期命中的示例课程 | 重点查看 |
| --- | --- | --- |
| 必修 | 信息系统基础（DEMO0001） | 2024 级、信息管理与信息系统、信管241 和信管242 |
| 专业拓展课 | 数据可视化实践（DEMO0002） | 专业显示计算机科学与技术，年级显示「未单独限选」 |
| 素质拓展课-科学素养 | 生活中的科学实验（DEMO0003） | 年级、专业均为「未单独限选」 |
| 素质拓展课-外语 | 学术英语交流（DEMO0004） | 同一课程有两个教学班，列表提示展开查看 |
| 素质拓展课-美育 | 音乐鉴赏（DEMO0005） | 课程类型显示为美育 |
| 素质拓展课-人文素养 | 城市与人文（DEMO0006） | 课程类型显示为人文素养 |
| 素质拓展课-创新创业课程 | 创新项目与创业基础（DEMO0007） | 课程类型完整显示 |
| 实践 | 信息系统实训（DEMO0008） | 兼容原有「实践」类别 |

「学术英语交流」的两个班可用于核对限制是否串班。在有该样例的测试环境中按「素质拓展课-外语」筛选，输入「学术英语」，再展开课程：

| 教学班号 | 年级 | 专业 | 学院与培养层次 | 特殊要求 |
| --- | --- | --- | --- | --- |
| DEMO-LANG-01 | 2024 级或 2025 级 | 信息管理与信息系统 | 经济管理学院、本科 | 大学英语四级成绩 > 500 分，或六级成绩 > 500 分 |
| DEMO-LANG-02 | 2026 级 | 计算机科学与技术 | 未单独限选 | 未公布 |

在开放轮次中打开第一个班的选课申请弹窗，预期仍显示该班自己的要求。测试到弹窗即可。四六级条件是展示内容，当前接口不会比对成绩。

上线后可以用现有测试账号 `user6` 做只读走查。在「选课与课表 → 课程查询与选课」选择含本科课程的已发布轮次，检查「课程类型」「面向对象」两列。在仍使用仓库演示数据的环境中，可选「2026秋补退选（本研打通）」并搜索「Java企业级开发」，预期显示「专业拓展课」、2024 级和本科。上表的 `DEMO` 数据只在隔离测试中加载。
